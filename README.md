# Verse

A responsive lyric canvas for iPad and Mac, inspired by [Verci](https://www.verci.xyz/).

## Open it

Serve this folder with any static file server, or deploy it to GitHub Pages. No build step is required. On iPad, open the deployed page in Safari and choose Share → Add to Home Screen. On Mac, use Safari’s Add to Dock option where available.

## Included

- Thirteen selectable lyric presentation styles
- Responsive layout for iPad and Mac
- Full-screen lyrics view, style browser, search, and quick settings
- Installable web app metadata

## Current limits

The player and lyrics are sample content. Spotify sync needs an OAuth flow and timed lyrics source. This preview uses original Verse branding and its own layout, informed by the public reference.
